## Persona
Gestor ou CTO de PME que tem múltiplos sistemas rodando separados (ERP, CRM, loja, planilha) e quer que eles "conversem" automaticamente. Não sabe bem o que é API mas entende o problema.

## Resposta Direta
Integrar dois sistemas via API custa, em média, R$ 5.000–25.000 por par de sistemas, dependendo da complexidade e se as duas APIs são abertas. Integrações simples (ERP → email, loja → planilha) ficam em R$ 2.000–8.000. Integrações complexas com transformação de dados, tratamento de erros e monitoramento: R$ 15.000–50.000. Alternativas no-code (Zapier, n8n) funcionam para fluxos simples e custam muito menos.
