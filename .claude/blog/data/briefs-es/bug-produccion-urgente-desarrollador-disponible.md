## Outline H2/H3

### H2: Sistema caído ahora — 5 minutos de triaje antes de llamar a nadie
#### H3: Caída total vs fallo parcial
- Caída total = 502/503/504, sin acceso, error de hosting/infra
- Fallo parcial = sistema responde pero feature concreta rota (checkout, login, integración)
- Diferencia importa: total = infra/db; parcial = código/integración
#### H3: Checklist 5 preguntas no técnicas
1. ¿Empezó tras un cambio reciente?
2. ¿Otros sistemas también caídos? (apunta a hosting global)
3. ¿Afecta a todos o solo a algunos usuarios?
4. ¿Hay mensaje exacto de error?
5. ¿Cuándo empezó? (timestamp)

### H2: 3 cosas que SÍ debes hacer mientras buscas dev
#### H3: Capturar evidencias antes de que se borren
- Pantallazo error con URL completa
- Hora exacta inicio
- Logs si tienes acceso (Vercel, Railway, cPanel, AWS Console)
- Quién hizo último despliegue / cambio

#### H3: Comunicar usuarios afectados YA
- Plantilla: "Estamos con incidencia técnica. Equipo trabajando. Próxima actualización en 30 min."
- Canales: WhatsApp, banner web, email broadcast, X/Twitter si público
- Silencio = cliente furioso

#### H3: Activar plan B operativo
- Clínica: agenda papel + WhatsApp recepción
- E-commerce: pedidos por WhatsApp/email
- Restaurante: pausar Glovo/Uber Eats
- B2B SaaS: comunicar clientes y SLA

### H2: Dónde encontrar desarrollador disponible AHORA en España
#### H3: Plantón emergencias agencia (recomendado para producción crítica)
- SystemForge: WhatsApp directo + diagnóstico gratis
- Tarifa: €110-160/h horario / €220-380/h fuera horario
#### H3: Marketplace freelance (Malt, Workana, Upwork)
- Riesgo: tiempo en encontrar
- Coste: €40-100/h
- Sin SLA real
#### H3: Comunidades dev (Telegram, Discord)
- Lento pero gratis
- Sin garantía de calidad
#### H3: Proveedor original (si responde)
- Si tu agencia/freelance original responde, primera opción
- Si no: el problema es la dependencia, no solo el bug

### H2: Cuánto cuesta una corrección emergencia (precios reales)
- Diagnóstico inicial: gratis (en SystemForge) o €80-150 en otros
- Bug simple (config, certificado, restart): €150-400
- Bug medio (código, integración): €400-1.500
- Bug complejo (BD corrupta, lógica negocio): €1.500-5.000
- Hackeo / restauración: €2.000-15.000

### H2: Cómo no caer en la próxima emergencia
- Monitorización + alertas (Sentry, BetterStack, Pingdom)
- Backups verificados semanalmente
- Staging environment antes de producción
- CI/CD con tests mínimos
- Plan de mantenimiento mensual
- Acceso emergencia documentado

### H2: Errores frecuentes en pánico
- Borrar logs antes de que llegue dev
- Desplegar parche sin testing
- Reiniciar todo sin diagnóstico
- Cambiar credenciales en pánico (rompe integraciones)
- Quedarse en silencio con clientes
- Pagar al primero que responde sin verificar
