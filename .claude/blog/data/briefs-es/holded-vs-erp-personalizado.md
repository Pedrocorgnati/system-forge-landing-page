## Outline H2/H3

### H2: Holded, Contasol y Sage50 — qué resuelven y dónde tocan techo
- Holded: facturación + CRM + contabilidad ligera, 8-150€/mes
- Contasol: contabilidad clásica autónomo/pyme pequeña
- Sage50: estándar muy implantado, modular pero rígido
- A3 (Wolters Kluwer): asesorías, fuerte en gestoría
- Punto donde se rompen: workflows custom, integraciones B2B, multi-sociedad compleja

### H2: 6 señales de que tu Holded ya no aguanta
1. Más de 3 hojas de cálculo paralelas para suplir lo que falta
2. Personal copiando datos manualmente entre Holded y otra herramienta
3. Importes mensuales de plan superiores a €400 (varios usuarios + módulos)
4. Imposible cumplir Verifactu personalizado en tu workflow
5. Cliente B2B exigiendo integración EDI o API que Holded no expone
6. Multi-empresa con consolidación = fricción permanente

### H2: ERP a medida — qué entrega de verdad
- Workflow exacto de TU operativa (no plantilla genérica)
- Multi-tenant y multi-sociedad nativo
- Integraciones API sin marketplace intermedio
- Verifactu integrado siguiendo TU lógica (link interno verifactu-integracion)
- Reporting BI sobre tus KPIs reales
- Propietario del código

### H2: Precios reales 2026 en España
| Scope | Inversión | Duración |
|-------|-----------|----------|
| ERP modular base (gestión, facturación, stock, Verifactu) | €25.000-45.000 | 3-5 meses |
| ERP completo + CRM + producción | €60.000-110.000 | 6-9 meses |
| ERP enterprise multi-sociedad + BI + integraciones | €120.000-250.000 | 9-14 meses |

Operativo: hosting €120-650/mes + mantenimiento evolutivo 10-15% año.

### H2: Break-even matemático
- Holded plan medio 3 usuarios: ~€2.400/año
- ERP medida €40.000 + €4.000/año mantenimiento + €3.000/año infra
- Solo coste suscripción: ROI nunca por precio
- ROI viene de: horas administrativas ahorradas + decisiones mejores + escapar a vendor lock-in

### H2: Cuándo Holded sigue siendo la respuesta correcta
- PYME <15 empleados
- Operativa estándar sin nichos
- Sin necesidad de integraciones API custom
- Equipo financiero pequeño
- Sin requisitos B2B enterprise

### H2: Migración real — riesgos y plan
- Datos históricos: 5+ años contabilidad migrados con script
- Plan de paralelo 1-2 meses
- Formación equipo: 2-4 semanas con manual interno
- Riesgo Verifactu: integración nueva debe certificarse antes
- Backup contabilidad antigua siempre accesible

### H2: Stack técnico recomendado para ERP a medida 2026
- Backend: Node.js/TypeScript + PostgreSQL + Drizzle ORM
- Frontend: Next.js + shadcn/ui
- Hosting: Vercel + Railway o servidor dedicado España
- Auth: Clerk o NextAuth + SSO si enterprise
- Integración Verifactu siguiendo XSD AEAT

### H2: Errores típicos al lanzar ERP a medida
- Querer migrar TODO en go-live (mejor por módulos)
- No medir antes de construir (qué proceso me cuesta más horas?)
- Saltar la documentación de procesos previa
- Empresa solo desarrolladora sin acompañamiento funcional
- Sin contrato evolutivo claro
