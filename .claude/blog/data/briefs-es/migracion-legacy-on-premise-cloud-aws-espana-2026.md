## Respuesta Directa
Una migración on-premise → AWS para pyme española cuesta €25.000–120.000 en 2026. Las 6 estrategias AWS (Rehost, Replatform, Refactor, Repurchase, Retire, Retain) tienen costes muy distintos: rehost desde €25k, refactor completo €120k+. RGPD + LOPDGDD exigen residencia de datos en UE — AWS Madrid (es-central-2) o Frankfurt. Costes ocultos más frecuentes: egress de datos, NAT Gateway, CloudWatch Logs, snapshots.
