## Response Diretta
Una migrazione on-premise → AWS per PMI italiana costa €25.000–120.000 nel 2026. Le 6 strategie AWS (le 6 R: Rehost, Replatform, Refactor, Repurchase, Retire, Retain) hanno costi molto diversi: rehost (lift-and-shift) a €25k, refactor completo a €120k+. GDPR impone residenza dati in UE (AWS Frankfurt/Milano), DPIA e data processing agreement. I costi nascosti più frequenti: egress dati, NAT Gateway, CloudWatch logs.
