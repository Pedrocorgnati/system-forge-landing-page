3. **Precios reales de CRM a medida en España 2026 (400 palabras)** — Desglose por complejidad:
   
   **CRM básico (contactos + pipeline + notas):**
   - Inversión: €5.000 - €12.000
   - Plazo: 6-10 semanas
   - Incluye: CRUD de contactos, pipeline visual, importación CSV, GDPR/LOPD básico
   
   **CRM intermedio (+ automatizaciones + reporting):**
   - Inversión: €12.000 - €25.000
   - Plazo: 10-16 semanas
   - Incluye: automatización de tareas, dashboard de KPIs, integración email/WhatsApp, roles y permisos
   
   **CRM avanzado (+ integraciones + IA):**
   - Inversión: €25.000 - €60.000
   - Plazo: 4-6 meses
   - Incluye: integración con ERP/facturación, scoring de leads con IA, API para integraciones externas

4. **Precios reales de ERP a medida en España 2026 (400 palabras)** — Desglose por módulos:

   - Inversión: €40.000 - €120.000
