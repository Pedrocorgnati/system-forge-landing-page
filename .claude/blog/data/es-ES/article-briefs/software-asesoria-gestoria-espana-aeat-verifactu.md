# Brief: Software para asesoría y gestoría española: integración AEAT, Verifactu y gestión de clientes

## Objetivo editorial

Capturar propietarios y responsables de asesorías y gestorías españolas que buscan actualizar su software frente a los cambios normativos de 2026 (Verifactu, TicketBAI). Diferenciar un sistema a medida de las soluciones genéricas (A3, Sage, Quipu) para despachos con procesos específicos o crecimiento rápido.

## Persona objetivo

**Responsable o propietario de asesoría o gestoría española (5-25 empleados, 200-1.500 clientes)** que lleva años usando A3, Sage o software sectorial genérico. Sufre con: gestión de documentos dispersos, comunicación con clientes por WhatsApp y email sin orden, falta de automatización en recordatorios de vencimientos fiscales, y la presión de adaptar sus sistemas a Verifactu y TicketBAI. Evalúa si vale la pena un sistema propio o seguir pagando la suscripción del software genérico.

## Respuesta directa (GEO — primeras 100 palabras)

Un software a medida para asesoría o gestoría española en 2026 cuesta entre 15.000€ y 45.000€, e incluye: portal de clientes, gestión de expedientes, automatización de vencimientos fiscales, integración con AEAT (Agencia Tributaria), Verifactu para facturas electrónicas obligatorias y TicketBAI para territorios forales. Las alternativas genéricas (A3, Sage, Quipu) cubren lo esencial pero no permiten procesos propios del despacho. El punto de equilibrio: si gestionáis más de 300 clientes con procesos diferenciados, un sistema a medida suele recuperarse en 2-3 años.

## Datos y ejemplos obligatorios (con € y normativa España)

**Normativa Spain-only:**
- AEAT (Agencia Estatal de Administración Tributaria): presentación telemática obligatoria para todos los profesionales fiscales
- Verifactu (Ley 18/2022 + Reglamento AEAT): obligatorio para emitir facturas a empresas desde 2026-2027
- TicketBAI: sistema obligatorio en Álava (desde 2022), Gipuzkoa (2023), Bizkaia (2024), Navarra (proceso de implantación)
- SII (Suministro Inmediato de Información): para gestorías que llevan clientes con facturación >6M€

**Precios 2026:**

| Solución | Precio/mes | Para quién |
|---|---|---|
| Quipu | 35€ - 65€/mes | < 100 clientes, básico |
| Holded Asesoría | 50€ - 150€/mes | 50-200 clientes |
| A3 Asesor | 150€ - 400€/mes | 200-1.000 clientes |
| Sage Despachos | 200€ - 500€/mes | 200-1.500 clientes |
| Sistema a medida (básico) | 15.000€-22.000€ total | Procesos específicos |
| Sistema a medida (completo) | 30.000€-45.000€ total | Multi-sede, >500 clientes |

**TCO a 3 años:**
- Sage Despachos (300 clientes): ~12.000€/año x 3 = 36.000€
- Sistema a medida: 35.000€ desarrollo + 5.000€/año x 3 = 50.000€
- Punto de equilibrio: >400 clientes con procesos específicos o necesidad de portal propio

**Caso práctico:**
- Gestoría Bilbao (80 clientes empresas, 5 empleados): A3 sin módulo TicketBAI — multa riesgo por no cumplir normativa foral. Solución: módulo TicketBAI + portal clientes a medida integrado con A3 — 18.000€, 10 semanas. Resultado: cumplimiento normativo foral, 15 clientes nuevos captados por diferencial del portal.

**Integraciones clave:**
- AEAT: API presentación de declaraciones (Mod. 303, 130, 111, etc.)
- Seguridad Social (Sistema RED): altas, bajas, variaciones
- Ayuntamientos: tasas y tributos locales (menos estandarizado)
- Google Drive / Dropbox: migración documental

## FAQ (mín. 5 preguntas en español natural)

**1. ¿Mi software de gestoría actual necesita actualizarse para Verifactu?**
Probablemente sí, aunque depende del proveedor. A3 y Sage ya están trabajando en actualizaciones. El problema viene si usáis un software más antiguo o uno desarrollado hace años sin soporte activo — en ese caso, actualizar puede costar más que cambiar de sistema. Consultad con vuestro proveedor antes del plazo de 2026.

**2. ¿Qué es TicketBAI y me afecta si estoy en Madrid o Barcelona?**
TicketBAI solo afecta a empresas y autónomos que operan fiscalmente en el País Vasco (Álava, Gipuzkoa, Bizkaia) y Navarra. Si vuestra gestoría lleva clientes con domicilio fiscal en esos territorios forales, necesitáis estar preparados para emitir y gestionar facturas TicketBAI. No afecta a empresas en régimen fiscal común (Madrid, Barcelona, etc.).

**3. ¿Vale la pena un portal de clientes propio o con Teams/Email es suficiente?**
Depende de cuántos clientes tengáis y qué volumen de documentos gestionéis. Con menos de 50 clientes, Teams o Google Drive puede ser suficiente. Con más de 150 clientes, un portal propio reduce un 40-60% el tiempo de gestión de documentos y consultas repetitivas (el cliente busca su información sin llamar a la gestoría).

**4. ¿Puedo integrar el sistema con mi programa de nóminas actual?**
Sí. Los sistemas a medida se desarrollan con conectores para los programas más usados en España: A3Nom, Sage Nóminas, Nominasol. Si el programa tiene API o exporta en XML/CSV, la integración es técnicamente viable.

**5. ¿Cuánto tiempo tarda en implementarse un sistema a medida para una gestoría?**
Un sistema básico (portal + expedientes + alertas): 10-14 semanas. Un sistema completo con integraciones AEAT + TicketBAI + nóminas: 16-24 semanas. La migración de datos históricos puede añadir 3-5 semanas adicionales.

**6. ¿Los datos de mis clientes están seguros en un sistema a medida?**
Sí, si se desarrolla correctamente. Debe incluir: cifrado de datos en reposo y en tránsito, autenticación de dos factores, registro de accesos (log de auditoría), y política de backup diario. Además, como gestoría que trata datos de terceros (vuestros clientes), estáis obligados por el RGPD a firmar un contrato de tratamiento de datos con el proveedor de software.
