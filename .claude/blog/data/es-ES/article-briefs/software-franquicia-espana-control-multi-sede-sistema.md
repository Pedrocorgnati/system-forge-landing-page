**Normativa Spain:**
- Contrato de franquicia: regulado por el RD 201/2010 de información precontractual — el sistema debe gestionar el registro de franquiciados y la documentación precontractual

- GDPR: datos de empleados y clientes de las sedes deben tratarse conforme al RGPD — el sistema debe separar datos por sede y gestionar DPA con cada franquiciado

## FAQ (mín. 5 preguntas en español natural)

**1. ¿Por qué no usar Odoo o Holded para gestionar varias sedes de franquicia?**
Odoo y Holded tienen módulos multi-empresa que funcionan bien para gestionar varias sociedades. Pero no están pensados para la dinámica franquiciador-franquiciado: no tienen roles diferenciados, no gestionan royalties, no tienen protocolos de operación ni comparativa de rendimiento entre sedes. Para redes con lógica de franquicia real, necesitáis algo más específico.

**2. ¿Puede cada franquiciado usar el sistema con su propia cuenta?**
Sí. En un sistema multi-tenancy para franquicias, cada franquiciado tiene su portal con acceso limitado a sus datos (sus ventas, sus empleados, sus incidencias). El franquiciador tiene visibilidad de todas las sedes, pero cada franquiciado solo ve la suya. Los datos están técnicamente separados (multi-tenancy), aunque consolidan en el dashboard central.

**3. ¿Cómo se calculan y cobran los royalties con el sistema?**
El sistema puede calcular royalties automáticamente en base a las ventas reportadas por cada franquiciado (fijo, porcentaje o mixto). Genera la factura automáticamente conforme a Verifactu, la envía al franquiciado y registra el pago. Esto elimina el proceso manual que en muchas redes ocupa 2-3 días al mes.

**4. ¿Funciona el sistema si algunas franquicias tienen TPV propio?**
Sí. El sistema puede integrarse con los principales TPVs del mercado español (Redsys, Ingenico) para importar las ventas automáticamente, sin que el franquiciado tenga que introducirlas a mano. Si el franquiciado ya tiene un TPV propio, se desarrolla un conector de datos específico.

**5. ¿Cuánto tiempo tarda en implementarse el sistema para toda la red?**
Para una red de 15 sedes: 14-20 semanas. El proceso incluye: análisis de procesos de la red, desarrollo del sistema central, configuración de cada sede y formación del equipo de central y franquiciados. Normalmente se empieza con un piloto de 2-3 sedes antes de desplegar al resto.
