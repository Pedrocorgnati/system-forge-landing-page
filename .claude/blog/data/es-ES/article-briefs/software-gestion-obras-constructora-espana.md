## Datos y ejemplos obligatorios (con € y normativa España)

**Normativa Spain-only:**
- Verifactu (Ley 18/2022): obligatorio para facturación a otras empresas — crítico en construcción donde el 90% de facturación es B2B
- Plataforma de Contratación del Estado: base de datos oficial de licitaciones públicas españolas — el software puede integrarla vía API
- Ley de Subcontratación en el sector de la construcción (Ley 32/2006): obligación de llevar el Libro de Subcontratación — el software debe generarlo automáticamente
- Seguridad y Salud (RD 1627/1997): plan de seguridad por obra — integrables en el sistema de documentación

## FAQ (mín. 5 preguntas en español natural)

**1. ¿No vale con Presto para el control de costes de obras?**
Presto es una herramienta excelente para control de costes y presupuestación, pero es solo eso: control de costes. No gestiona subcontratistas, no genera partes diarios, no hace facturación ni Verifactu, y no integra con vuestro sistema contable. Para una gestión completa de la constructora, necesitáis o integrar Presto con otros sistemas (complejo) o un sistema integral a medida.

**2. ¿Cuánto tiempo tarda en implantarse un sistema de gestión de obras?**
Un sistema básico: 12-16 semanas. Un sistema completo con integración de datos históricos (obras anteriores, proveedores): 16-24 semanas. Lo que más tarda es la migración de datos existentes (presupuestos en Excel, histórico de subcontratistas) y la formación del equipo en obra y oficina.

**3. ¿El sistema puede usarse desde obra (tablet, smartphone)?**
Sí, si se desarrolla con diseño mobile-first. Los sistemas a medida incluyen app o web responsive para que los jefes de obra puedan introducir partes diarios, validar albaranes y consultar desviaciones desde la propia obra sin necesidad de ir a oficina.

**4. ¿Cómo funciona Verifactu en una constructora?**
Cada factura que emitís a vuestros clientes (promotores, ayuntamientos, otros) debe generar un registro en AEAT en tiempo real. El sistema de facturación debe estar homologado Verifactu. En una constructora esto es especialmente importante porque las certificaciones de obra son facturas de importes elevados — el control es mayor.

**5. ¿Puede el software ayudarme a presentarme a más licitaciones públicas?**
Sí. El sistema puede integrarse con la Plataforma de Contratación del Estado para alertaros de licitaciones en vuestro sector y zona geográfica. Además, si tenéis histórico de obras bien documentado en el sistema, generáis las memorias y documentación técnica para licitaciones mucho más rápido.
