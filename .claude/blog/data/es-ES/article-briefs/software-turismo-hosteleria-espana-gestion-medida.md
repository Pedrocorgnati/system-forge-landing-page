## Datos y ejemplos obligatorios (con € y normativa España)

**Sector turismo España:**
- >14% del PIB español (datos INE 2025)
- 85 millones de turistas internacionales en 2025 (récord)
- 300.000+ empresas turísticas en España (mayoría PYMEs)
- Solo el 35% de agencias de viajes medianas tiene sistema de gestión digital integrado (Exceltur 2024)

**Normativa Spain:**
- IATA (International Air Transport Association): licencia necesaria para emisión de billetes de avión — el sistema debe integrarse con el GDS correspondiente
- ATOL/AITO: no aplica en España — el equivalente español es la Garantía de Viaje
- Ley de Viajes Combinados (RD 116/2021): obliga a gestionar seguros de insolvencia, depósitos garantizados y procedimientos de cancelación específicos — el sistema debe gestionar estos requisitos
- Verifactu: facturas de agencia B2B (empresas que compran viajes de empresa) — obligatorio
- Bizum: integración crítica para pagos de turismo (viajes locales, experiencias, actividades)

## FAQ (mín. 5 preguntas en español natural)

**1. ¿Necesito licencia IATA para tener mi propio sistema de reservas?**
La licencia IATA es necesaria si queréis emitir billetes de avión directamente. Para actividades, hoteles, turismo rural o paquetes sin vuelo, no necesitáis licencia IATA. Si queréis incluir vuelos en vuestros paquetes, podéis hacerlo como agente de IATA o integrando con un GDS (Amadeus, Sabre) que gestione la emisión.

**2. ¿Qué me exige la Ley de Viajes Combinados si vendo paquetes?**
Si vendéis viajes combinados (transporte + alojamiento mínimo), el RD 116/2021 obliga a: garantía de insolvencia (seguro o aval bancario), información precontractual detallada, y procedimientos de cancelación específicos con plazos legales. Vuestro sistema de gestión debe documentar automáticamente toda esta información y generar los contratos conforme a la ley.

**3. ¿Bizum funciona para cobrar paquetes de viaje de varios miles de euros?**
Bizum tiene límite de 1.000€ por transacción (puede ampliarse hasta 2.000€ con algunos bancos). Para paquetes de mayor importe, Bizum no es viable como pago único, pero sí para depósitos y señales. La solución habitual: Bizum para el 20-30% de señal + transferencia o tarjeta para el resto.

**4. ¿Cuánto tiempo tarda un sistema de reservas a medida en estar funcionando?**
Sistema básico (web + reservas + pagos): 8-12 semanas. Sistema completo con CRM + proveedores + Verifactu + cancellations: 14-20 semanas. Para agencias con temporada alta definida (verano, Navidad), recomendamos empezar el desarrollo 6 meses antes de la temporada objetivo.

**5. ¿Puedo integrar el sistema con Booking.com o Airbnb para hoteles o casas rurales?**
Sí. Las principales plataformas OTA (Booking, Airbnb, Expedia) tienen APIs de integración para gestión de disponibilidad y precios. El sistema puede sincronizar vuestro calendario en todas las plataformas desde un solo panel, evitando overbookings. Esta integración añade normalmente 3.000€-8.000€ al coste de desarrollo.
