## Objecoes do Leitor
1. PowerBI resolve tudo → Para dados internos sim; dashboards sob medida integram dados de multiplas fontes e oferecem UX customizada
2. Dashboard e so um grafico bonito → Dashboard bem feito e ferramenta de decisao; o diferencial esta na logica de negocios, nao na estetica
3. Qualquer dev faz dashboard → Visualizacao de dados e especialidade; um dev fullstack generico nao domina D3.js, Recharts ou logica de BI
