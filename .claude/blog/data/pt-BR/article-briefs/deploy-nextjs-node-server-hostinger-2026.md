## Conteudo Obrigatorio
- **Resposta nos primeiros 100 palavras:** Em 2026, o Hostinger VPS (a partir de R$ 28/mês) suporta Next.js com Node server via PM2. O Business Shared Hosting ainda não suporta SSR nativo. Para deploy: criar Dockerfile ou usar PM2, configurar variáveis de ambiente no painel, e ajustar o next.config.js com output: 'standalone'. A maioria dos problemas vem de versão Node incompatível (exige Node 18+).
- **Dados reais:** Hostinger VPS: R$28–R$85/mês. Vercel Pro: R$130/mês. Para tráfego até 100k/mês: Hostinger VPS é suficiente e mais barato.
