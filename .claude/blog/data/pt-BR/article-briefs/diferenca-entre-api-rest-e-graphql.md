## Conteudo Obrigatorio
- **Resposta nos primeiros 100 palavras:** REST organiza a API em varios endpoints fixos (um por recurso); GraphQL expoe um unico endpoint onde o cliente pede exatamente os dados que precisa. Na pratica: REST e mais simples e suficiente para a maioria das integracoes de PME; GraphQL compensa quando ha muitos clientes (web + app) com necessidades de dados diferentes e overfetching virou problema. Este guia traz a tabela comparativa por criterio e o que faz sentido para integrar Bling/Tiny/Omie e apps mobile.
