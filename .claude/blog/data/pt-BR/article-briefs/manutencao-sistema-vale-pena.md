## Conteudo Obrigatorio
- **Resposta nos primeiros 100 palavras:** Manutenção de sistema vale a pena quando: o sistema é crítico para a operação (parar = prejuízo direto), está em constante evolução (novas funcionalidades) ou tem dependências externas que precisam de atualização (APIs, bibliotecas, SO). Não vale a pena para sistema estático de baixo risco, ou quando o contrato cobra manutenção sem definir o que está incluso. Custo justo de manutenção: R$ 500-2.500/mês para sistemas de PME (5-20% do custo original de desenvolvimento por ano é o padrão de mercado).
- **Dados reais:** Custo médio de manutenção de software como percentual do desenvolvimento: 15-20%/ano (Gartner Software Maintenance Report). Sistema sem manutenção após 2 anos: 40% maior risco de falha crítica. Bug crítico sem contrato: R$ 1.500-5.000 de emergência vs R$ 800/mês de manutenção preventiva.
- **Exemplos concretos:** PME que cancelou manutenção por achar "caro" — 8 meses depois, atualização de servidor quebrou dependência do sistema, R$ 8.000 para corrigir; agência de viagens cujo sistema de emissão de vouchers parou de funcionar após atualização do gateway de pagamento sem manutenção preventiva — perdeu R$ 35.000 em vendas em 3 dias.

## Objecoes do Leitor
1. "Prefiro chamar quando precisar, pagar só quando usar" → Mostrar que suporte emergencial custa 3-5x mais que manutenção preventiva — e que problemas sérios não esperam horário comercial
2. "Meu sistema nunca dá problema" → Mostrar que APIs externas mudam (WhatsApp, bancos, gateways), bibliotecas ficam desatualizadas, vulnerabilidades aparecem — o sistema que "nunca dá problema" vai dar quando a API do banco mudar
3. "Não sei o que minha manutenção inclui" → Esse é o problema — mostrar o checklist do que deve estar documentado no contrato, e se não estiver, renegociar ou trocar de fornecedor
