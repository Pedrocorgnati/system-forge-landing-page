## Conteudo Obrigatorio
- **Resposta nos primeiros 100 palavras:** MCP (Model Context Protocol) é o padrão aberto da Anthropic que permite conectar agentes de IA diretamente a fontes de dados e ferramentas da empresa — banco de dados, ERP, CRM, APIs internas — de forma segura e controlada. Um MCP server personalizado custa entre R$ 18.000 e R$ 55.000 para desenvolvimento e pode ser implementado em 4–8 semanas.
- **Dados reais:** Desenvolvimento MCP: R$18k–R$55k. Manutenção mensal: R$1.200–R$3.500. Casos reais: redução de 70% no tempo de busca de informações internas após implantação.
- **Exemplos concretos:** Distribuidora (MCP para consulta de estoque em tempo real via Claude): 40 atendentes economizam 2h/dia cada. Escritório jurídico (MCP para acesso ao jurídico de contratos): 85% menos tempo em buscas manuais.
- **Comparacoes:** MCP server vs webhook vs API REST vs integração via n8n.
- **FAQ:** MCP é seguro? Meus dados saem para a nuvem? Funciona com Claude e com outros LLMs? Preciso de cloud?

## Objecoes do Leitor
1. "Meus dados são sensíveis demais" → MCP pode rodar on-premise. Os dados nunca saem da infraestrutura da empresa — apenas a resposta processada vai para o LLM.
2. "Parece muito novo e arriscado" → MCP é o padrão oficial da Anthropic, já suportado por Claude, Cursor, Windsurf, Claude Code. Não é experimental.
3. "Temos ERP legado e APIs complicadas" → MCP foi desenhado exatamente para isso. Adaptadores para SAP, Totvs e sistemas legados já existem.
