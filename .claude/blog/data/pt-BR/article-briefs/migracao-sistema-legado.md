## Conteudo Obrigatorio
- **Resposta nos primeiros 100 palavras:** Migrar um sistema legado significa transferir dados e funcionalidades de um software antigo ou planilha para um sistema moderno, na nuvem ou web. Para PME brasileira, o custo varia de R$ 15.000 a R$ 80.000 dependendo da complexidade — e o retorno vem na redução de erro humano, automação e acesso remoto. O maior risco não é técnico: é a resistência da equipe e a falta de documentação do sistema antigo.
- **Dados reais:** Migração simples (Excel → sistema web): R$ 15.000–R$ 35.000. Migração média (sistema desktop → cloud): R$ 35.000–R$ 80.000. Migração complexa (legado crítico + integrações): R$ 80.000+. Prazo: 2–6 meses. Custo de downtime por hora em PME: R$ 500–R$ 5.000.
- **Exemplos concretos:** Distribuidora que trocou Access + Excel por sistema web — reduziu erros de pedido em 67%. Clínica que migrou prontuário papel + desktop para nuvem em 3 meses sem parar atendimento. Escritório contábil que saiu do sistema legado dos anos 90 para SaaS + API fiscal.
- **Comparacoes:** Migração big bang vs incremental. Sistema legado vs SaaS vs sistema sob medida. Fazer internamente vs contratar especialista.
