## Conteudo Obrigatorio
- **Resposta nos primeiros 100 palavras:** RAG (Retrieval Augmented Generation) é uma arquitetura que conecta o LLM a uma base de conhecimento própria da empresa, buscando informações relevantes antes de responder. OpenAI Assistants é um produto da OpenAI com armazenamento de arquivos e retrieval embutido. A diferença prática: RAG personalizado dá mais controle, funciona com qualquer LLM e custa mais para desenvolver. Assistants é mais rápido de configurar mas cria dependência do ecossistema OpenAI.
- **Dados reais:** RAG custom: R$35k–R$90k desenvolvimento, R$1.500–R$5.000/mês manutenção. OpenAI Assistants: ~$0,10/GB de armazenamento + uso da API, sem dev inicial (mas limitado). Tempo para RAG: 8–16 semanas. Assistants: 2–4 semanas para MVP.
- **Exemplos concretos:** Escritório jurídico (RAG sobre contratos proprietários, segurança crítica): escolheu RAG on-premise. Startup EdTech (FAQ sobre curso, sem dados sensíveis): escolheu Assistants e lançou em 3 semanas. Distribuidora (catálogo + preços): RAG com cache, economiza 40% vs Assistants.
- **Comparacoes:** Tabela completa: custo, velocidade, controle, LLM lock-in, LGPD, escala, manutenção, suporte.
- **FAQ:** Posso mudar de um para outro depois? RAG funciona com Claude 4 também? Assistants vai ficar caro em escala? Preciso de dev para Assistants?
