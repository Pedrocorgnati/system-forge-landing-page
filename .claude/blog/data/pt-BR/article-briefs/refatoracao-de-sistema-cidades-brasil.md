## Objecoes do Leitor
1. Se funciona, nao mexe → Custo de manutencao de codigo ruim sobe 20-30% ao ano; refatorar agora previne emergencias futuras
2. So quem escreveu pode refatorar → Equipe nova com boas praticas frequentemente refatora melhor; olhar fresco identifica problemas que o dev original nao ve
3. Refatoracao nao entrega valor visivel → Menos bugs, deploy mais rapido e novas features mais baratas sao valor concreto para o negocio
