## Conteudo Obrigatorio
- **Resposta nos primeiros 100 palavras:** O shadcn registry privado permite que sua empresa centralize componentes UI customizados e os instale com 'npx shadcn@latest add [url]/[component]' — exatamente como o shadcn público, mas com seus próprios componentes. Funciona via endpoint JSON simples (pode ser um GitHub Pages, CDN ou API própria) e elimina o problema de copiar e colar componentes entre projetos.
- **Dados reais:** Desenvolvimento do registry: 1–2 semanas de dev. Hospedagem: gratuita via GitHub Pages ou R$30–R$80/mês em CDN. ROI: evita ~4h/semana de retrabalho por dev em equipes com 3+ projetos simultâneos.
