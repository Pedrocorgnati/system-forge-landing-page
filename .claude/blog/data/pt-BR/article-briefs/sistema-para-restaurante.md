## Conteudo Obrigatorio
- **Resposta nos primeiros 100 palavras:** Um sistema para restaurante e um software que integra PDV, controle de estoque, KDS (cozinha), delivery e gestao financeira. Para restaurantes com faturamento acima de R$ 50.000/mes, controlar CMV com precisao pode significar R$ 3.000-8.000/mes de economia — a diferenca entre lucro e prejuizo num setor com margem media de 10-15%.
- **Dados reais:** Sistemas prontos (Saipos, Consumer, Goomer): R$ 200-800/mes. Sistema personalizado: R$ 15.000-35.000 investimento inicial. CMV ideal para restaurante: 28-35%. Sem controle de ficha tecnica: CMV real pode chegar a 40-50%.
- **Exemplos concretos:** Restaurante com 80 lugares que reduziu CMV de 42% para 31% com ficha tecnica automatizada e controle de desperdicio; rede de 3 lanchonetes que unificou cardapio e estoque em sistema unico, eliminando R$ 12.000/mes em perdas.
- **Comparacoes:** Saipos vs Consumer vs Goomer vs sistema proprio

## Objecoes do Leitor
1. "Saipos/Consumer ja resolvem tudo" → Reconhecer que para restaurante unico com operacao simples, sistema pronto cobre 80%. Mas quando tem delivery proprio, programa de fidelidade customizado ou rede com multiplas unidades, as limitacoes aparecem rapido.
2. "Restaurante tem margem apertada, nao posso investir R$ 20k" → Mostrar conta: CMV descontrolado custa R$ 3.000-8.000/mes. Sistema que baixa CMV de 42% para 31% se paga em 3-4 meses. Alem disso, pode comecar com MVP focado em estoque+ficha tecnica (R$ 12.000-15.000).
3. "Minha equipe nao vai usar sistema — cozinheiro nao mexe com computador" → KDS e tablet na cozinha com interface minima (foto do prato, quantidade, tempo). Garcom usa comanda eletronica no celular. Zero papel, zero erro de comunicacao.
