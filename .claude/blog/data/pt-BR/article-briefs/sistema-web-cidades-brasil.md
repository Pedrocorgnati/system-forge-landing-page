## Objecoes do Leitor
1. Sistema desktop e mais seguro → Sistemas web modernos com HTTPS e autenticacao robusta sao tao seguros quanto desktop; a vantagem e acesso de qualquer lugar
2. Preciso de sistema rapido como desktop → Frameworks modernos (Next.js, React) entregam performance similar a desktop com PWA
3. Qualquer webdesigner faz sistema web → Sistema web exige backend, banco de dados, autenticacao e logica de negocios; webdesigner faz sites, nao sistemas
