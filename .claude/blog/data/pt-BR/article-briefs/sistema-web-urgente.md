## Conteudo Obrigatorio
- **Resposta nos primeiros 100 palavras:** Se voce precisa de um sistema web urgente, defina primeiro: quem vai usar (clientes, equipe interna, ambos) e as 3-5 funcionalidades criticas. Um sistema web MVP com autenticacao, CRUD principal e relatorios basicos pode ser entregue em 3-6 semanas com investimento de R$ 15.000 a R$ 60.000. Para sistemas mais simples (formularios inteligentes, portal de consulta), o prazo pode ser de 2 semanas. A stack que mais acelera entregas hoje: Next.js (front + API) + Supabase (banco + auth).
- **Dados reais:** Sistema web MVP: R$ 15.000-60.000. Sistema completo: R$ 30.000-150.000. Prazo MVP: 3-6 semanas. Sistema simples: 2-3 semanas. Hospedagem moderna (Vercel/Railway): R$ 0-500/mes para PMEs. 78% dos sistemas web de PMEs sao acessados primariamente por desktop durante horario comercial (StatCounter BR).
- **Exemplos concretos:** (1) Empresa de contabilidade que precisava de portal para clientes enviarem documentos e acompanharem processos — sistema web com upload, timeline de status e notificacoes em 4 semanas. 150 clientes migraram do email para o portal no primeiro mes. (2) Cooperativa agricola que precisava de sistema de cotacao online para 80 produtores — formulario inteligente + painel administrativo + relatorios PDF em 3 semanas.
- **Comparacoes:** Sistema web custom vs Retool (low-code) vs Google AppSheet vs Notion/Coda. Tabela com: custo, prazo, customizacao de UI, integrações, escalabilidade, propriedade do codigo.

## Objecoes do Leitor
1. "Nao da para usar Google Forms ou Notion?" → Para coleta de dados simples, sim. Para sistema com autenticacao, permissoes, workflows e relatorios, nao. O limite dessas ferramentas aparece rapido: sem controle de acesso, sem automacoes complexas, sem marca propria. Se voce precisa de SISTEMA, precisa de sistema.
2. "Sistema web nao e lento comparado com app nativo?" → Sistemas web modernos (Next.js, React) sao tao rapidos quanto apps nativos para a maioria dos casos. A diferenca e irrelevante para sistemas de gestao, portais e ferramentas internas. Apps nativos so fazem sentido quando voce precisa de GPS, camera ou push notifications offline.
3. "Como garantir seguranca com prazo apertado?" → Seguranca nao e feature — e fundacao. Autenticacao robusta (OAuth, JWT), HTTPS, validacao de inputs e principio de menor privilegio sao implementados desde o dia 1, nao adicionados depois. Framework moderno (Next.js + Supabase) ja traz essas protecoes embutidas.
