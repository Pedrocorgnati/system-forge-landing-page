## Objecoes do Leitor
1. "Vou chamar quando precisar, sem contrato" → Mostrar custo real: sem contrato, suporte urgente fora de horário comercial custa R$ 150-400/hora. Com contrato mensal, cobre manutenção preventiva e suporte corretivo por preço fixo
2. "Meu sistema nunca dá problema" → Todo sistema eventualmente falha — banco de dados cheio, servidor sem espaço, atualização de SO quebrando dependência. A questão não é SE vai falhar, é quando
3. "Não tenho o código do meu sistema" → Mostrar que isso é exatamente o problema — e como suporte especializado em engenharia reversa funciona (com ressalvas e custos maiores)
