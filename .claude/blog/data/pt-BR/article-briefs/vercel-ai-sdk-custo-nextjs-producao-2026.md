## Conteudo Obrigatorio
- **Resposta nos primeiros 100 palavras:** O Vercel AI SDK em produção custa a soma de: consumo de LLM (OpenAI/Anthropic, pago diretamente ao provedor) + hospedagem Vercel (Pro R$ 130/mês ou Enterprise). O SDK em si é open source gratuito. Para um app com 1.000 chamadas/dia usando GPT-4o mini, o custo mensal fica em torno de R$ 180–R$ 450 em API + R$ 130 de Vercel Pro = ~R$ 580/mês.
- **Dados reais:** Vercel Pro: R$130/mês. GPT-4o mini: ~$0,60/1M tokens. Claude Sonnet 4.6: ~$3/1M tokens. Para 1k chamadas/dia: R$180–R$450/mês de LLM.
