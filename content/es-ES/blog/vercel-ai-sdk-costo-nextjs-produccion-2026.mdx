# Vercel AI SDK en Producción: ¿Cuánto Cuesta de Verdad en 2026?

El Vercel AI SDK en producción tiene tres componentes de coste: **consumo de LLM** (pagado directamente al proveedor — OpenAI o Anthropic), **hosting Vercel** (Pro a $20/mes o Enterprise) y **observabilidad**. El SDK en sí es open-source y gratuito. Para una app con 1.000 llamadas/día usando GPT-4o mini, la factura mensual se sitúa entre **€30 y €50 totales**. Con el mismo volumen en Claude Sonnet 4.6, sube a €65–€95. La sorpresa no está en el SDK — está en el modelo que elijas.

Soy Pedro Corgnati, fundador de SystemForge. He puesto en producción apps Next.js con Vercel AI SDK desde chatbots internos (200 llamadas/día) hasta asistentes de ventas en e-commerce con picos de 4.500 llamadas/día.

## Optimización de Costes

**1. Routing por complejidad**
Consultas simples → Gemini Flash o GPT-4o mini. Razonamiento complejo → Claude Sonnet. Un clasificador ligero puede enrutar las llamadas automáticamente y reducir el coste total un 40–60%.

**2. Caché semántica**
Si el 40% de los usuarios hace preguntas similares, la caché semántica (Redis + similaridad vectorial) puede reducir los costes LLM un 30–50%. Especialmente efectivo en chatbots de soporte con un FAQ muy consultado.

**3. Límites de gasto**
Configura topes mensuales en OpenAI y Anthropic antes de ir a producción. Los bucles no controlados existen — un error de código puede generar miles de llamadas en minutos.

**4. Agrega los contextos**
No envíes el historial completo de la conversación en cada llamada. Resume los turnos anteriores o usa una capa de memoria separada para conversaciones largas.

## FAQ

**¿El Vercel AI SDK es realmente gratuito?**
Sí. El paquete npm `ai` es open-source y gratuito. Pagas separadamente el proveedor LLM y el hosting Vercel.

**¿Funciona con modelos self-hosted (Ollama, Llama)?**
Sí. El SDK soporta APIs compatibles con OpenAI. Ollama funciona — útil para apps con datos sensibles sujetos a GDPR.

**¿Funciona con Claude, Gemini y otros además de OpenAI?**
Sí. Hay providers oficiales para OpenAI, Anthropic, Google Gemini, Mistral, Groq y más via `@ai-sdk/{provider}`. El principal beneficio frente al SDK de OpenAI directo es la portabilidad: cambiar de GPT-4o a Claude o Gemini requiere una sola línea de código, no un refactoring completo.

**¿Cuál es la diferencia entre Edge Functions y Serverless Functions para rutas AI?**
Edge Functions tienen menor cold start (~0ms) pero APIs de Node.js limitadas. Serverless tienen Node.js completo pero cold start de 100–500ms. Para respuestas AI en streaming, Serverless Functions son típicamente más flexibles. Usa `export const runtime = 'nodejs'` para ser explícito y evitar comportamientos inesperados en el entorno Edge.

**¿A qué escala Vercel Pro deja de ser suficiente?**
Aproximadamente a 20.000–50.000 llamadas AI/día. A esa escala, revisa el dashboard de uso de Vercel con cuidado y considera negociar precios Enterprise.

## Sorpresas de Facturación Reales a Vigilar

Basándose en facturación real de producción, estos son los costes que pillan por sorpresa a los equipos:

**1. Bucles de retry sin límite**
Si tu app hace retry en error sin un límite de backoff, una interrupción del LLM puede generar miles de llamadas en minutos. Establece siempre un conteo máximo de retries (2–3) con un retardo de backoff.

**2. Acumulación del contexto conversacional**
Cada llamada que añade el historial completo de la conversación al contexto aumenta el conteo de tokens por llamada. Una conversación de 20 mensajes a 500 tokens cada uno significa que la 20ª llamada envía 10.000 tokens de entrada en lugar de 500. Usa una capa de resumen para conversaciones largas.

**3. Prompt injection**
Un prompt mal protegido puede explotarse para generar outputs extremadamente largos. Limita la longitud del input del usuario (máx. 2.000 caracteres para la mayoría de casos de uso) y establece `maxTokens` en la llamada al modelo.

**4. Optimización para el mercado español (RGPD)**
Si tu app recopila datos de usuarios españoles/europeos, considera:
- Usa regiones EU en Vercel (eu-west-1) y Supabase (eu-west-1) para la residencia de datos
- Configura logs de auditoría para las llamadas AI que procesan datos personales
- Evita enviar PII (nombre, email, DNI) en el prompt — usa IDs anonimizados
- Verifactu 2025: si tu app genera facturas, asegúrate de que el flujo AI no elude la homologación

**Checklist pre-producción:**
- Establece topes de gasto en OpenAI/Anthropic (límites rígidos, no solo alertas)
- Añade validación del input para rechazar inputs demasiado largos
- Registra cada llamada LLM con conteo de tokens (Langfuse o capa de logging propia)
- Activa alertas de uso de Vercel al 70% de los límites de tu plan
