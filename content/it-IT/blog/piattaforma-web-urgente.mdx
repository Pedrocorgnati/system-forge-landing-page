Una piattaforma web MVP con autenticazione, CRUD principale e reportistica base puo essere consegnata in 3-6 settimane con investimento di €12.000-50.000. Per sistemi piu semplici (form intelligenti, portale di consultazione) il tempo scende a 1-2 settimane. La stack che oggi accelera di piu le consegne in Italia: Next.js 16 + Supabase. Parti dall'essenziale, lancia, evolvi col feedback reale.

## Cosa fare quando hai bisogno di una piattaforma web urgente

Prima di cercare un fornitore, rispondi a queste 5 domande. Definiscono l'80% del progetto.

**1. Chi la usa?** Clienti esterni, team interno, entrambi? Definisce livello di design, complessita autenticazione, permessi.

**2. Quali sono le 3-5 funzioni essenziali?** Non le 20 che vorresti. Le 3-5 senza le quali la piattaforma non serve a nulla.

**3. Da dove vengono i dati?** Sistema nuovo con database proprio? Integrazione con gestionale esistente (TeamSystem, Zucchetti, Danea)? Excel da migrare?

**4. Hai bisogno di SDI o pagamento integrato dal giorno 1?** Se vendi → si (vedi [software contabilita e fatturazione elettronica SDI/IVA](/blog/software-contabilita-fatturazione-elettronica-sdi-iva) e [integrazione PagoPA nel tuo software](/blog/pagopa-integrazione-software-aziendale-2026)). Se gestisci dati interni → no. Cambia la complessita di ~2-4 settimane di sviluppo.

**5. Mobile-first o desktop?** Per portale clienti consumer → mobile-first obbligatorio. Per dashboard interna → desktop puo bastare.

## Lo stack che accelera nel 2026

La stack che oggi consegna piu velocemente in Italia per progetti di questo tipo.

**Next.js 16 (App Router, Cache Components).** Framework React full-stack. Server-side rendering nativo, SEO ottimo, deploy in 5 minuti su Vercel. Cache Components di Next 16 semplificano performance senza overhead di ottimizzazione manuale.

**Supabase.** Postgres + Auth + Storage + Edge Functions in un unico servizio gestito. Per MVP web vale come "backend pronto": database relazionale serio, auth con magic link/OAuth, file storage, real-time subscription. Costo €25-200/mese tipicamente.

**Vercel deploy < 5 minuti.** Push su Git → deploy automatico. Preview URL per ogni pull request. Niente DevOps a giorno 1.

**shadcn/ui per UI rapida.** Componenti Tailwind copia-incolla, accessibili, modificabili. Eviti ridisegnare bottoni, form, tabelle.

**Resend per email transactional.** API moderna, prezzi sani (€20/mese fino a 50k email), arrival rate ottimo. Sostituisce Mailgun e SendGrid per nuovi progetti.

**Cosa NON usare per MVP urgente.** Microservizi (overhead di setup), Kubernetes (totalmente sovradimensionato), GraphQL custom (REST basta), microfrontend (per MVP, mai), infrastruttura on-premise (perde 1-2 settimane solo in setup). Tutte queste scelte si possono giustificare in fase post-PMF, mai in MVP urgente.

## Scope minimo che funziona in 3 settimane

Cinque blocchi che, combinati, costituiscono un MVP serio in 3 settimane.

**Auth con magic link.** Supabase Auth out-of-the-box. Niente password da gestire, niente recupero password complesso, mobile-friendly.

**1-2 entita con CRUD.** Una tabella principale (es. clienti, ordini, prenotazioni) con create/read/update/delete. Eventualmente una secondaria (es. note su clienti, righe ordine).

**1 dashboard / report.** Tre KPI principali in cima, tabella sotto con filtri, esportazione CSV. Non serve di piu in MVP.

**Notifiche email transactional (Resend).** Conferma registrazione, conferma azione critica, reminder. Template HTML semplici.

**Audit log basico.** Chi ha fatto cosa quando. Una tabella `audit_logs` con user_id, action, entity, timestamp. Salva problemi futuri.

Questi 5 blocchi insieme: 3 settimane di lavoro per un freelance senior, 4 per uno mid, 2 per uno senior AI-augmented.

## Errori che ritardano una piattaforma urgente

Cinque errori ricorrenti che vedo settimanalmente.

**Scope creep "giusto un'altra cosina".** Il founder durante lo sviluppo aggiunge requisiti. Ogni "cosina" costa 3-7 giorni. Dopo 4 cosine, l'MVP di 3 settimane diventa di 7. Mitigazione: change request scritte, blocco scope dopo kickoff.

**Volere SSO Azure AD nel MVP.** A meno che il cliente sia enterprise dal giorno 1, magic link basta e avanza. SSO aggiunge 1-2 settimane di sviluppo + complessita perpetua.

**Design custom prima di validare.** Un brand designer per il logo + shadcn/ui per i componenti vince sempre vs design system custom in MVP. Risparmi 2-3 settimane.

**Microservizi per 3 entita.** Monolite Next.js + Postgres copre fino a 100k utenti senza scaling problems. Microservizi sono per dopo.

**Migrare ERP esistente nel mezzo.** Voler integrare il TeamSystem aziendale "gia che ci siamo" durante MVP triplicate la complessita. Lancia MVP standalone, integra in fase 2.

## Checklist legale / fiscale prima di andare live

Cinque punti obbligatori spesso dimenticati.

**Cookie banner conforme GDPR.** Iubenda (€7-30/mese) o Cookiebot (€9-90/mese). Setup 30 minuti. Senza, sei fuori legge.

**Privacy policy + termini d'uso.** Generabili con Iubenda o redatti da consulente (€300-800). Devono coprire dati raccolti, base giuridica, retention, diritti utente.

**Designazione DPO se trattamento sensibile.** Sanita, dati biometrici, profilazione massiva. Costo DPO esterno €100-400/mese.

**SDI integration se vendita.** Se la piattaforma genera fatture, integrazione Fatture in Cloud o Aruba SDI obbligatoria. Aggiungi 5-10 giorni sviluppo.

**Accessibilita WCAG.** Obbligatoria se PA o pubblica utilita. Per privati: best practice ma non bloccante. Audit professionale €1.500-3.500 una tantum.

## FAQ

**Posso davvero avere una piattaforma in 2 settimane?**
Si, per scope ridotto: form intelligenti, portale consultazione semplice, MVP super-minimale. Per CRUD completo con auth e dashboard servono almeno 3 settimane.

**Quanto costa il dominio + hosting + SSL nei primi 12 mesi?**
Dominio .it €15-30/anno, dominio .com €15-50/anno. Hosting Vercel €0-240/anno per MVP. SSL incluso (Let's Encrypt). Totale: €30-300 il primo anno.

**Cosa succede dopo il lancio? Manutenzione?**
Tipicamente 4-8 ore/mese di evolutiva nel primo trimestre, scendendo a 2-4 ore dopo. Costo €300-1.500/mese secondo necessita. Sempre meglio contratto retainer leggero che spot.

**Posso aggiungere funzioni dopo senza rifare tutto?**
Si, se la stack iniziale e modulare. Next.js + Supabase scala fino a sistema completo aggiungendo moduli incrementalmente. Eviti rifacimenti.

**SDI / fattura elettronica integrata: quanto costa in piu?**
Integrazione con Fatture in Cloud o Aruba SDI: €2.500-5.500 di sviluppo aggiuntivo + €5-50/mese di canone API. Tempi: +5-10 giorni di lavoro.

**E se il dev sparisce a meta?**
Mitigazione standard: repo nel tuo GitHub, deploy CI/CD su tuo Vercel, milestone settimanali con consegna verificabile. Se sparisce, prendere in carico richiede tipicamente 1-2 settimane con altro dev senior senza perdita di lavoro fatto.

**Quanto influisce avere il design system pronto vs partire da zero?**
Avere logo + palette + tipografia decisi prima del kickoff salva 4-7 giorni di sviluppo. Senza: il dev sceglie default ragionevoli (shadcn/ui base), risultato accettabile ma generico. Per MVP la scelta intelligente e accettare il default e re-skinning post-PMF.

**Posso lanciare in beta privata prima del go-live pubblico?**
Si, e fortemente raccomandato. Tipicamente 1-2 settimane di beta con 5-15 utenti reali invitati, raccolta feedback, fix bug critici, poi public launch. Costo addizionale: zero (parte del calendario standard).
