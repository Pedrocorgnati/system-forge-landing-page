# Modernizar Sistema Legado em 2026: Quanto Custa, Refatorar ou Reescrever do Zero

Modernizar um sistema legado no Brasil custa entre R$30.000 e R$200.000 dependendo da complexidade, linguagem original (Delphi, VB6, Clipper, Access) e volume de dados. Refatoração parcial fica entre R$15.000 e R$60.000. Reescrita completa vai de R$50.000 a R$250.000. A maioria das empresas erra ao escolher reescrever tudo do zero — a abordagem por módulos reduz risco e custo. Veja nosso [guia completo de manutenção e modernização de sistemas](/blog/guia-completo-manutencao-de-sistema) para o contexto estratégico completo.

*Por Pedro Corgnati — Fundador da SystemForge, desenvolvedor full-stack com mais de 20 projetos de modernização de sistemas legados no Brasil.*

Em mais de 20 projetos de modernização de sistemas legados, o padrão que vemos é sempre o mesmo: empresa que cresceu com um sistema desenvolvido há 10–15 anos, que ninguém mais consegue manter (o programador original saiu ou morreu), que trava com mais de 100 usuários simultâneos ou que não roda mais no Windows 11.

## Quanto custa modernizar um sistema legado no Brasil

| Abordagem | Custo | Prazo | Risco |
|-----------|-------|-------|-------|
| Refatoração parcial (módulo crítico) | R$15k–60k | 2–6 meses | Baixo |
| Migração para cloud (lift and shift) | R$20k–50k | 1–4 meses | Baixo-médio |
| Modernização incremental por módulos | R$40k–120k | 6–18 meses | Médio |
| Reescrita total | R$50k–250k | 8–24 meses | Alto |
| Integração com APIs modernas (sem reescrita) | R$8k–30k | 2–4 meses | Baixo |

O custo varia muito com a linguagem original. Sistemas em **Delphi** são mais fáceis de modernizar porque têm lógica de negócio bem estruturada. Sistemas em **Access** com lógica em macros VBA são os mais difíceis — lógica enterrada em planilhas sem documentação.

## Refatorar vs reescrever: a decisão mais difícil de TI

Essa é a decisão que mais vemos ser tomada errado. A reescrita total parece atraente ("começar do zero, fazer direito dessa vez"), mas 68% dos projetos de reescrita total estão com o orçamento ou prazo estourado até o ano 1.

**Quando refatorar faz sentido:**
- O sistema tem lógica de negócio complexa e documentada (mesmo que implicitamente)
- Os dados estão em banco estruturado (Firebird, Interbase, SQL Server)
- Você pode identificar 1–3 módulos críticos que precisam de modernização
- Há risco operacional de parar tudo para reescrever

**Quando reescrever faz sentido:**
- O sistema não tem banco de dados real (tudo em arquivos texto ou Access)
- A lógica de negócio mudou completamente desde que o sistema foi criado
- O sistema tem menos de 10 usuários e poucos dados históricos
- Você precisa de arquitetura moderna para uma funcionalidade que é impossível adicionar ao legado

A maioria dos casos: refatoração incremental. Você moderniza o módulo de maior dor primeiro, valida, depois passa para o próximo. Veja [migração de sistema legado passo a passo](/blog/migracao-sistema-legado) para o processo detalhado de migração de dados.

## Sinais de que seu sistema legado está travando o crescimento

1. **Performance**: o sistema demora mais de 3 segundos para abrir telas comuns
2. **Escalabilidade**: trava quando mais de 20 usuários acessam simultaneamente
3. **Manutenção**: qualquer correção de bug leva semanas porque ninguém entende o código
4. **Integração**: você não consegue conectar com APIs modernas (WhatsApp, Pix, e-NF)
5. **Mobile**: sistema não funciona em celular ou tablet
6. **Segurança**: o sistema não tem autenticação moderna (2FA, LGPD compliance)
7. **Dependência**: roda apenas em Windows XP ou versões antigas, não compatível com hardware novo

Se você marcou 3 ou mais desses pontos, a modernização não é mais uma opção — é urgente. Saiba também [como integrar sistemas legados sem reescrever do zero](/blog/integrar-sistemas-legados-sem-reescrever) como primeira etapa antes da modernização completa.

## Como o SystemForge moderniza sistemas legados

Nossa abordagem de modernização tem 5 etapas:

**Etapa 1: Auditoria técnica (1–2 semanas)**
Mapeamos todo o sistema legado: linguagem, banco de dados, volume de dados, dependências externas, lógica de negócio documentada e implícita. Resultado: relatório com complexidade e riscos.

**Etapa 2: Decisão de abordagem**
Com base na auditoria, recomendamos: refatorar, reescrever módulo por módulo ou migrar para cloud. Apresentamos custo e prazo de cada opção.

**Etapa 3: Projeto piloto (módulo de maior dor)**
Começamos pelo módulo que mais trava a operação. Desenvolvemos, testamos em paralelo com o sistema atual, validamos os resultados.

**Etapa 4: Migração de dados**
A parte mais crítica. Migramos os dados históricos com validação dupla — antes e depois da migração, comparando totalizadores e registros.

**Etapa 5: Go-live e suporte**
Sistema em produção com 30–90 dias de suporte próximo. O legado fica rodando em paralelo até a equipe ter confiança total no novo sistema.

Para uma distribuidora de alimentos em Porto Alegre com sistema Delphi de 2003 (4.000 clientes, 18 anos de histórico), fizemos modernização incremental em 14 meses por R$95.000. O sistema novo rodou em paralelo por 3 meses antes do corte. Zero perda de dados, zero parada operacional.

## Erros que encarecem a modernização de sistema

**Erro 1: Não documentar o sistema legado antes de começar**
Se o único desenvolvedor que conhece o sistema vai sair da empresa, documente tudo antes de iniciar a modernização. O custo de reverse-engineering de código sem documentação pode dobrar o projeto.

**Erro 2: Querer migrar sem treinamento da equipe**
A equipe que usa o sistema há 10 anos tem hábitos profundos. Modernização de sistema sem treinamento tem taxa de rejeição alta — as pessoas voltam ao legado por hábito.

**Erro 3: Subestimar a migração de dados**
"Os dados estão no banco, é só exportar." Não é. Dados históricos têm inconsistências acumuladas por anos. A limpeza e transformação dos dados é um projeto dentro do projeto.

**Erro 4: Parar tudo para reescrever**
Empresa que para as operações para trocar o sistema de uma vez está apostando tudo em um projeto de 12 meses. Se algo der errado, não tem volta fácil.

## Migração para cloud: o que muda no processo

Muitos sistemas legados rodam localmente (on-premise) em servidores físicos velhos. Migrar para cloud não significa reescrever — significa mudar onde o sistema roda. Consulte o [guia completo de modernização de software](/blog/guia-completo-modernizacao-de-software) para entender as opções de cloud e arquitetura moderna.

**Lift and shift** (mover sem reescrever): pega o sistema como está e coloca em servidor na nuvem (AWS, Azure, Google Cloud). Custo: R$5.000–20.000. Resultado: sistema mais estável, com backup automático, acessível de qualquer lugar.

**Modernização cloud-native**: aproveita a migração para refatorar o sistema com arquitetura moderna. Custo maior, resultado muito melhor em médio prazo.

Para sistemas Delphi ou VB6, lift and shift é frequentemente a primeira etapa — você estabiliza o sistema na cloud, depois moderniza incrementalmente.

## Quando contratar vs fazer internamente

**Contratar faz sentido quando:**
- A linguagem do sistema legado é obsoleta (Clipper, Delphi 7, VB6, FoxPro)
- Não há ninguém interno que conhece o sistema
- A migração envolve banco de dados com anos de dados críticos
- Você precisa de garantia contratual sobre prazos e resultados

**Fazer internamente funciona se:**
- Você tem um desenvolvedor sênior que conhece o sistema legado
- O projeto é uma refatoração de módulo pequeno
- O prazo é flexível (12+ meses)

## Perguntas Frequentes

### Quanto custa modernizar um sistema legado no Brasil?
Refatoração parcial: R$15.000–60.000. Modernização incremental: R$40.000–120.000. Reescrita total: R$50.000–250.000. O custo varia muito com a linguagem original e volume de dados.

### É melhor refatorar ou reescrever um sistema legado?
Na maioria dos casos, refatoração incremental por módulos é mais segura e mais barata. Reescrita total faz sentido apenas quando a lógica de negócio mudou completamente ou quando o sistema não tem banco de dados estruturado. Leia [quando a manutenção do sistema compensa](/blog/manutencao-sistema-vale-pena) para análise de custo-benefício.

### Quanto tempo leva para modernizar um sistema legado?
De 2 meses para refatoração de módulo único até 24 meses para reescrita completa de sistema grande. Modernização incremental de sistema médio: 8–18 meses.

### O que é migração para cloud de sistema legado?
É mover o sistema para rodar em servidores na nuvem (AWS, Azure, Google Cloud) sem necessariamente reescrever o código. Resolve problemas de hardware obsoleto e adiciona backup automático. Custo: R$5.000–20.000.

### Como migrar dados de sistema legado sem perder nada?
A migração deve ser feita com validação dupla: antes da migração, você extrai relatórios do sistema antigo; depois da migração, compara com o novo sistema. O sistema legado fica rodando em paralelo por 30–90 dias como segurança.
