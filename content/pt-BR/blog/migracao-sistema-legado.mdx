Migrar um sistema legado significa transferir dados e funcionalidades de um software antigo, planilha ou sistema desktop para um sistema moderno na nuvem. Para PME brasileira, o custo varia de R$ 15.000 a R$ 80.000 dependendo da complexidade — e o retorno vem na redução de erro humano, acesso remoto, automação e integração com outros sistemas. O maior risco não é técnico: é a falta de documentação do sistema antigo e a resistência da equipe. Antes de decidir entre migrar ou integrar, vale entender [estratégias para integrar sistemas legados sem reescrever tudo](/blog/integrar-sistemas-legados-sem-reescrever).

Sou Pedro Corgnati, fundador da SystemForge — desenvolvedor full-stack com experiência em projetos de modernização de sistemas para PMEs. Em vários projetos de migração que realizamos, o padrão é sempre o mesmo: a empresa esperou mais tempo do que devia e o custo de não migrar superou o custo de migrar há anos.

## Sinais de que seu sistema legado precisa ser migrado agora

Antes de falar em custo e metodologia, um checklist honesto. Se você responder "sim" para 3 ou mais itens, a migração é urgente:

- O sistema roda apenas em um computador específico da empresa
- Você não consegue acessar os dados remotamente (home office, reunião fora)
- O suporte do fornecedor foi descontinuado ou custa caro demais
- A importação/exportação de dados para outros sistemas é manual (copia e cola, Excel)
- A empresa depende de 1–2 pessoas que "sabem como o sistema funciona"
- Relatórios gerenciais exigem trabalho manual de consolidação
- Clientes reclamam de processos lentos que dependem do sistema antigo
- O sistema travou ou corrompeu dados nos últimos 12 meses

Se sua planilha de Excel tem 15 abas, macros que "só o Rodrigo sabe mexer" e serve como banco de dados — parabéns, você tem um sistema legado disfarçado de planilha.

## Quanto custa migrar um sistema legado em 2026

O custo depende de quatro fatores: volume de dados, complexidade de regras de negócio, número de integrações necessárias e estado da documentação do sistema atual.

| Tipo de Migração | Exemplo | Custo | Prazo |
|-----------------|---------|-------|-------|
| Simples | Excel → [sistema web personalizado](/blog/sistema-personalizado-urgente) básico | R$ 15.000–R$ 35.000 | 6–12 semanas |
| Média | Sistema desktop → nuvem com integrações | R$ 35.000–R$ 80.000 | 12–24 semanas |
| Complexa | Legado crítico + múltiplas integrações + alto volume | R$ 80.000+ | 6–12 meses |

**Mas quanto custa NÃO migrar?**

Esse cálculo raramente é feito. Considere por semana:
- 5h de trabalho manual para consolidar relatórios que um sistema moderno geraria automaticamente: R$ 500–R$ 1.500
- Erros de pedido ou faturamento por processos manuais: R$ 200–R$ 2.000 em retrabalho
- Risco de perda total de dados (disco rígido, vírus, ransomware): inestimável
- Dificuldade de contratar: funcionários novos fogem de sistemas dos anos 90

Em 12 meses, o custo de manter um sistema legado problemático frequentemente supera o custo de migrar.

## Como migrar sem parar a operação: metodologia

O medo de parar a empresa durante a migração é legítimo. Por isso, a abordagem certa é a **migração paralela** — nunca o "big bang" para sistemas críticos.

**Fase 1: Documentação e mapeamento (2–4 semanas)**
- Mapear todos os dados do sistema antigo (estrutura, volume, integridade)
- Documentar regras de negócio que estão "na cabeça" dos usuários
- Identificar integrações com outros sistemas (contabilidade, NF-e, bancos)

**Fase 2: Desenvolvimento do sistema novo (4–12 semanas)**
- Construir o sistema moderno com base na documentação
- Importar os dados históricos em ambiente de homologação
- Validar com usuários-chave antes do go-live

**Fase 3: Migração paralela (4–8 semanas)**
- Ambos os sistemas rodam ao mesmo tempo
- Operação continua no sistema antigo
- Equipe vai testando o novo sistema gradualmente
- Comparar resultados entre os dois sistemas diariamente

**Fase 4: Go-live e desligamento**
- Confirmar que 100% dos dados históricos estão corretos no sistema novo
- Treinamento final da equipe
- Desligar sistema antigo (mas manter backup por 90 dias)

## Como o SystemForge faz migrações de sistemas

Em projetos de migração que realizamos, seguimos um princípio: **o dado do cliente é sagrado**. Nenhum dado se perde, nenhuma informação histórica é descartada sem autorização explícita.

## Excel vs sistema web: quando a planilha virou um problema

O Excel é o sistema legado mais comum no Brasil. Metade das PMEs que nos procuram com "problemas de gestão" na verdade estão gerenciando tudo em planilhas complexas que cresceram sem planejamento.

**Quando Excel ainda resolve:**
- Análises pontuais que não precisam de atualização em tempo real
- Cálculos simples para poucos usuários
- Protótipos e testes de processo

**Quando Excel virou problema (e precisa ser migrado):**
- Mais de 3 pessoas editam a mesma planilha
- Você precisa acessar dados de clientes em campo (celular, tablet)
- Erros de digitação causam problemas financeiros ou operacionais recorrentes
- Você não consegue gerar relatório sem montar manualmente
- A planilha tem mais de 10.000 linhas e ficou lenta
- Macros VBA "quebraram" com atualização do Office

A migração de Excel para sistema web é geralmente a mais rápida e com melhor ROI — porque os dados já estão estruturados (mesmo que de forma não ideal) e a regra de negócio pode ser documentada.

## Riscos reais e como mitigá-los

**Perda de dados históricos**
Mitigação: backup completo antes de qualquer ação. Validação registro a registro no sistema novo antes do go-live. Manutenção de backup do sistema antigo por 90 dias após migração.

**Resistência da equipe**
O maior risco nas migrações não é técnico. É humano. "Aprendi no sistema antigo, não quero aprender de novo." Mitigação: envolver um usuário-chave de cada departamento na fase de testes. Quem ajuda a construir, adota. Lembre que após a migração, pode valer a pena considerar [modernização de software com entrega urgente](/blog/modernizacao-de-software-urgente) para ganhar velocidade na nova fase.

**Regras de negócio perdidas**
Muitas regras existem "na cabeça" de funcionários antigos. Mitigação: entrevistas estruturadas com todos os usuários antes de iniciar o desenvolvimento. Documentar cada exceção, cada "mas quando X acontece, fazemos Y".

**Downtime durante go-live**
Mitigação: go-live em período de baixo movimento (fim de semana ou mês baixo do setor). Plano de rollback documentado: se algo errar nas primeiras 24h, como voltar para o sistema antigo.

## Perguntas Frequentes

### O que é migração de sistema legado?
É o processo de transferir dados e funcionalidades de um software antigo (desktop, Access, planilha Excel) para um sistema moderno (web, nuvem). Envolve exportação de dados históricos, desenvolvimento do sistema novo e validação de integridade.

### Quanto tempo leva uma migração de sistema legado?
Depende da complexidade. Migração simples (Excel → sistema web básico): 6–12 semanas. Migração média (sistema desktop → nuvem): 12–24 semanas. Sistemas legados críticos com alto volume de dados e integrações: 6–12 meses.

### Posso perder dados na migração?
Com metodologia correta, não. A abordagem de migração paralela mantém o sistema antigo rodando enquanto o novo é validado. Os dados são comparados registro a registro antes do go-live. Backup completo é feito antes de qualquer operação.

### Preciso parar a empresa para migrar?
Não. A metodologia de migração paralela permite que a operação continue no sistema antigo enquanto o novo é validado. O go-live é planejado para um período de baixo movimento, com plano de rollback documentado.

### Como migrar de Excel para sistema web?
O processo tem 4 etapas: (1) documentar todas as regras de negócio da planilha; (2) limpar e estruturar os dados; (3) desenvolver o sistema web baseado nas regras; (4) migrar dados históricos com validação. Custo típico: R$ 15.000–R$ 35.000.

### Vale a pena migrar um sistema que "funciona"?
Funcionar e ser eficiente são coisas diferentes. Calcule: quantas horas/semana são gastas em tarefas manuais que um sistema moderno automatizaria? Multiplique pelo custo da hora. Em geral, o ROI da migração é de 12–24 meses.
